#Sistema Integral de Gestión de Restaurante (SIGR)

Descripción
SIGR es una aplicación web orientada a la gestión operativa de restaurantes.

El sistema permite administrar:

Usuarios
Menús
Pedidos
Reservas
Facturación
Reportes
Objetivo
Automatizar las operaciones principales de un restaurante mediante una plataforma web centralizada.
